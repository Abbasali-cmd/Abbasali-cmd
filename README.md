## Research Project

### 🔬 Hybrid Abbas Ali Metric (HAAM)

HAAM is an experimental distance metric I'm developing for mixed numerical and categorical data.

It combines transformed numerical differences, feature weights, scaling, and categorical mismatch. I'm testing its performance in K-nearest neighbours (KNN) classification and comparing it with Euclidean, Manhattan, and Gower distance.

[Explore the HAAM repository](https://github.com/Abbasali-cmd/hybrid-abbas-ali-metric)
